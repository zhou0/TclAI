# TclAI

TclAI is a lightweight, cross-platform Tcl/Tk LLM client. It features a modern Material Design 3 navigation rail and a conversational interface with local history persistence.

Key features include:
- **LLM Connectivity**: Chat with multiple providers using OpenAI-compatible APIs.
- **Provider Management**: Add, verify, and store custom LLM providers and models.
- **Settings & Persistence**: Configure global system prompts, select models, and manage API keys securely.
- **Localization**: Full support for English, Simplified Chinese, and Traditional Chinese.
- **Cross-Platform**: Native look and feel on Windows, macOS, and Linux.

Easily integrate and switch between your favorite AI services in a clean, responsive desktop application.
